## Browser acceptance

Before the code QA, exercise the delivered product through its browser surface: load the page or app the task changes, follow the stated user path, and record a failing interaction as a numbered QA finding with the path and the observable result. Cite the URL or command and its output; keep screenshots out of the repository.

Use the QA verdicts and outcome fields below. A browser-only gap is a finding against this work; a gap that exists only inside the repository belongs to the code QA turn that follows.
