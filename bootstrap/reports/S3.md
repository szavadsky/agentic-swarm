## Deviations / notes
- `sessionsDir` is not passed to adapter constructors: adapters are built by S4's CLI registration (`launch.ts`/`cli/**`). S3 records `TurnResult.transcript` per step and hands `paths.sessionsDir` to the digest scout; S4 must construct adapters with it.
- Architect prompt gained one line (`debt closed: <what>` in `forward`) so the summary can derive closed debt; digest prompt now says the script pre-writes the cost/turn table. Both are code-driven; snapshots include them.
- The digest covers all records before the current launch; launch-id markers arrive with S4's session layout. A `digest` run alias is required once a previous launch exists; S4 pre-flight should check it.
- Cancelled slugs are also restored if edited (beyond merged/finished), keeping slugs spent.
- Variant of "processed": a steer moves only when the architect answers it; otherwise it is re-read next boundary and named in owner attention.
